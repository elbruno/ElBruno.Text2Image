- `ConfigCommand` — manage provider configs (show, set, remove, path)
- `SecretsCommand` — manage credentials (set, list, remove, test)
- `DoctorCommand` — diagnostics (list providers, check health)
- `ProvidersCommand` — show available providers and their capabilities
- `VersionCommand` — display CLI version
- `SetupWizard` — interactive Spectre.Console prompts for first-run setup
- `ConsoleHelpers` — `Slug()`, `Mask()`, `IsInteractive()` utilities
- `ProgressRenderer` — async-friendly progress bar adapter
- `InternalsVisibleTo` for test access
