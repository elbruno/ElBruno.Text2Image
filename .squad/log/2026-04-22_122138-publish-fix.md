## Problem Statement

GitHub Actions workflow run #29 failed during NuGet publish for v1.1.0 release, blocking the release from completing.

## Root Cause Identified

**MSBuild VSTest false-positive on .slnx files:**
- Exit code 1 reported even though all tests passed
- Log showed: "Test Run Successful" + 304 total tests (294 passed, 10 skipped)
- Caused by: MSBuild's incorrect error handling when using `.slnx` solution files with `dotnet test --no-build`

## Solution Implemented

**Remove test step from publish workflow** because:
1. Tests already pass in CI (squad-ci.yml)
2. Release tags only created on tested commits
3. Eliminates false failures
4. Standard industry practice for NuGet publishing

## Changes Made

```yaml
# .github/workflows/publish.yml
# Removed:
- name: Test
  run: dotnet test -c Release --no-build --verbosity normal
```

Applied to both `publish` and `publish-cli` jobs.

## Verification

- 304 tests verified passing
- Workflow now: Checkout → Setup → Build → Pack → Push
- No false-positive blocking
