## Work Summary

Implemented complete secrets infrastructure: three secret store implementations, `SecretResolver` with resolution chain, `ConfigStore` for app config persistence, and DI registration. All operations async; platform-aware (DPAPI Windows-only).

## Deliverables

- `EnvVarSecretStore` — read-only env var store (`T2I_{PROVIDER}_{FIELD}` convention)
- `DpapiSecretStore` — Windows DPAPI encryption with automatic per-user decryption
- `PlainFileSecretStore` — cross-platform plaintext JSON with Unix 0600 permissions
- `SecretResolver` — resolution chain (CLI override → env → DPAPI → file → null)
- `ConfigStore` — JSON persistence for `AppConfig` with source-gen serialization
- `AddCliInfrastructure()` DI registration with all stores and resolvers
- Tests: All green (platform-aware DPAPI tests, file permissions on Unix)

## Key Decisions

1. **Secrets storage format** — `{provider}::{field}` keying; separate on-disk formats per store (JSON for plaintext/DPAPI)
2. **DeleteAsync behavior** — Deletes from all available stores (best-effort removal)
3. **Atomic writes** — Uses `.tmp` + `File.Replace` for data integrity
