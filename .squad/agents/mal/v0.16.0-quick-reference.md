## 🚀 Key Features

### 1. Skill File Deployment
```bash
t2i init                 # Creates both .github and .claude skill files
t2i init --target github # GitHub Copilot only
t2i init --target claude # Claude Code only
t2i init --force         # Overwrite existing files
```

**Creates:**
- `.github/skills/t2i/SKILL.md` → GitHub Copilot
- `.claude/skills/t2i/SKILL.md` → Claude Code

### 2. Embedded SKILL.md
- Ships inside CLI assembly (embedded resource)
- Version-locked to CLI version
- Always up-to-date with installed tool

### 3. No Upgrade Command
**Decision:** Use `dotnet tool update --global ElBruno.Text2Image.Cli`  
**Rationale:** Don't reinvent .NET SDK tooling
