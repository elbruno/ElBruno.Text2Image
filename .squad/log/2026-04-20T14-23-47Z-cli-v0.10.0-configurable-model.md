## Key Outcomes

### Feature: Configurable Model Names
- Users can set model names per provider: `t2i config set foundry-mai2.model MAI-Image-2e`
- Defaults: MAI-Image-2, FLUX.2-pro (backward compatible)
- Setup wizard prompts with defaults shown

### Architecture: RequiredFields/RequiredSecrets Split
- `IProviderAdapter.RequiredFields` → non-sensitive config (endpoint, model)
- `IProviderAdapter.RequiredSecrets` → sensitive data (apiKey only)
- `t2i config show` displays fields plain, secrets masked

### Backward Compatibility
- Existing configs (no Model field) work via adapter defaults
- Endpoint fallback chain: ProviderConfig → SecretResolver → default
- Zero breaking changes
