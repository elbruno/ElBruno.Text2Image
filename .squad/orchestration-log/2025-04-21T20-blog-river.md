## Key Design Decisions

### 1. Model Positioning: Four Quadrants

Models positioned in decision matrix rather than simple list:

- **GPT-Image-1.5 & GPT-Image-2:** Reliable workhorses (Azure OpenAI)
- **FLUX.2 Pro:** Photorealism champion (art, cinematic)
- **FLUX.2 Flex:** Text specialist (logos, UI, packaging)
- **MAI-Image-2:** Production optimizer (speed, sync API, batch workflows)

**Benefit:** "Pick the right tool for the job" vs "We have options, pick one"

### 2. Code Examples: Progressive Complexity

1. **Sample 1:** Hello World (GPT-Image-1.5)
2. **Sample 2:** Product photography (GPT-Image-2)
3. **Sample 3:** Art direction (FLUX.2 Pro)
4. **Sample 4:** Logo design (FLUX.2 Flex)
5. **Sample 5:** Batch generation (MAI-Image-2)
6. **Sample 6:** Dependency injection (enterprise pattern)

**Benefit:** New users start simple; architects see production patterns

### 3. CLI Examples: Real Workflows

Practical examples beyond `t2i "hello"`:

- Batch logo generation
- Product photography pipelines
- Diagram generation with perfect text
- Switching providers mid-workflow
- **GitHub Actions CI/CD integration** (most impactful)

**Benefit:** Users see automation potential immediately

### 4. Performance Table: Honest, Actionable

Included speed estimates, cost models, async patterns.

**Benefit:** Developers make informed choices without trial-and-error

### 5. Prompt Engineering Patterns: Reusable Templates

Provided 3 copy-paste patterns:

- Style Guide (photorealistic renders)
- Design Requirements (logos/UI)
- Iterative Refinement (prompt evolution)

**Benefit:** Immediate workflow integration
